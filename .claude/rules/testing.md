# Тесты

- Имя теста описывает поведение: `rejects kept fish below min length`.
- Время фиксировано: `ClockService` подменяется в API, `now` передаётся в `shared`; никаких тестов, зависящих от сегодняшней даты.
- Граничные случаи обязательны для дат: полночь по `Europe/Warsaw`, переход на летнее/зимнее время, период через Новый год.
- Интеграционные тесты: свой PostgreSQL (Testcontainers), данные через фабрики `test/factories`, а не общий seed. Каждый тест независим.
- Для каждого маршрута `/orgs/:orgId/*` — тест «админ чужой организации → 403».
- Внешние сервисы (P24, Nominatim, SMTP) — фейки; реальные вызовы в тестах запрещены.
- E2E (Playwright) — `PAYMENTS_PROVIDER=fake`, селекторы по роли/label (`getByRole`), не по CSS-классам.
- Не удаляй и не ослабляй существующий тест, чтобы он прошёл. Если тест неверен — объясни почему в описании PR.
