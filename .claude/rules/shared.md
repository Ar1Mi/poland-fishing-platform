# Пакет shared

- Только чистый TypeScript: без Node API, DOM, Prisma, NestJS, React и без чтения текущего времени (`now` передаётся параметром).
- Код работает и в браузере (PWA офлайн), и на сервере — это суть ADR-0003.
- Правило проверки улова = отдельный файл в `src/rules/catch/` + свой файл тестов; ID правила (`BR-xx`) совпадает с `docs/02-business-rules.md`.
- Любое изменение правил — сначала обнови `docs/02-business-rules.md`, затем тесты, затем код.
- Публичный API пакета — только через `src/index.ts`.
