# Проверка перед PR

## Изменения

!`git diff --stat main...HEAD`

## Шаги

1. Запусти и исправь всё, что падает:
   - `pnpm lint`
   - `pnpm typecheck`
   - `pnpm test`
   - `pnpm --filter api test:e2e` — если изменён `apps/api`
2. Передай ревью субагенту **code-reviewer**: ID задачи, список изменённых файлов и ссылки на нужные разделы `docs/`. Он не видел, как писался код, — так ревью независимо.
3. Пройди его замечания:
   - **Блокирующие** — исправь.
   - **Существенные** — исправь или объясни пользователю, почему нет.
   - **Мелкие** — по усмотрению.
4. Проверь Definition of Done из `AGENTS.md` по пунктам.
5. Подготовь описание PR по `.github/pull_request_template.md` и покажи пользователю. Не пушь без явной просьбы.
