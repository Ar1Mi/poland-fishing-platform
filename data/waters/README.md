# Данные каталога водоёмов

CSV для импорта каталога (FR-22, ADR-0007). Полные списки łowisk собирает автор вручную из публичных источников (RZGW Wody Polskie, округа PZW); в репозитории — только `mazowieckie.sample.csv` с несколькими строками для проверки импорта (значения примерные, `sourceRef` с префиксом `SAMPLE-`).

## Импорт

```bash
pnpm --filter api import:waters data/waters/mazowieckie.sample.csv
```

или `POST /api/v1/admin/waters/import` (суперадмин, multipart, поле `file`, до 1 МБ). Отчёт: `{ created, updated, failed: [{ row, error }] }`. CLI печатает тот же отчёт и завершается с кодом 2, если есть неудачные строки.

Строки без координат геокодируются через Nominatim (`NOMINATIM_URL`, `NOMINATIM_USER_AGENT` в `.env`): не чаще 1 запроса в секунду, поэтому первый импорт большого файла идёт минуты — для него удобнее CLI (у HTTP-запроса есть таймаут). Если геокодер не отвечает 3 раза подряд, до конца файла используются только кэшированные результаты. Результаты, включая «не найдено», кэшируются в `GeocodeCache` — повторный импорт запросов не делает. Чтобы исправить «не найдено», уточните `geocodeQuery` (новый запрос) или укажите `lat`/`lng`.

## Формат

UTF-8 (BOM допустим), разделитель `,`, поля с запятой — в кавычках. Первая строка — заголовок со всеми колонками ниже (порядок любой, лишние колонки запрещены). До 5000 строк в файле. `row` в отчёте — номер строки файла, с которой начинается запись (заголовок = 1), как в редакторе. Строки только из запятых (их оставляют таблицы в конце файла) пропускаются.

| Колонка | Обязательна | Значение |
| --- | --- | --- |
| `source` | да | `RZGW`, `PZW`, `OSM`, `MANUAL` (`USER` — только предложения из приложения) |
| `sourceRef` | да | Идентификатор в источнике (номер obwodu, код łowiska), до 100 символов. `source + sourceRef` — ключ: повторный импорт обновляет запись |
| `name` | да | Название, до 200 символов |
| `type` | да | `LAKE`, `RIVER`, `RESERVOIR`, `POND`, `CANAL` |
| `region` | да | Воеводство в нижнем регистре, как в `REGIONS` (`mazowieckie`) |
| `externalOwnerName` | нет | Użytkownik rybacki |
| `externalInfoUrl` | нет | Ссылка на источник/правила, только `http(s)://` |
| `lat`, `lng` | вместе | Десятичные градусы с точкой, в границах Польши; пусто — геокодирование |
| `geocodeQuery` | если нет координат | Текст для Nominatim, напр. `"Zalew Zegrzyński, mazowieckie"` (поиск ограничен Польшей) |

Повторный импорт перезаписывает только поля из CSV (название, тип, регион, владелец, ссылка, координаты). Статус, организация, описание и публикация принадлежат платформе и не меняются. Для полей из CSV источник истины — файл: ручные правки этих полей откатываются следующим импортом. Пустые `externalOwnerName`/`externalInfoUrl` очищают поле.
