# 10. Дизайн-система

Визуальный язык интерфейса. Обоснование — [ADR-0011](adr/0011-design-system.md). Макет (основы, компоненты, четыре демо-экрана): <https://claude.ai/artifact/1wiSmcx3B2uAMY4CLNLA4j> — доступ по приглашению.

Токены задаются один раз в теме Tailwind (`apps/web/src/index.css`). В компонентах — только семантические классы (`bg-primary`, `text-muted-foreground`), никаких hex.

Текст на подложках статусов: `#14532F` (success), `#6B4000` (warning), `#7F1A13` (danger).

Правила:

- Контраст текста ≥ 4.5:1 (≥ 3:1 для текста от 24 px). Белый текст допустим на Toń 700 / 900, Spławik 600, Success, Danger.
- Статус — всегда цвет + иконка + текст; цвет никогда не единственный носитель смысла.
- Тёмной темы в первой версии нет.

## Типографика

Onest — заголовки и текст; IBM Plex Mono — номера разрешений, суммы, размеры, даты и коды ошибок. Оба шрифта — из бандла (`@fontsource`), наборы `latin`, `latin-ext`, `cyrillic`.

| Стиль | Размер / интерлиньяж | Начертание | Применение |
| --- | --- | --- | --- |
| Display | 40 / 44 | 700 | Только десктоп: заголовки разделов |
| H1 | 28 / 34 | 700 | Заголовок экрана, вердикт проверки |
| H2 | 20 / 28 | 600 | Заголовок раздела, шапка вложенного экрана |
| Body | 16 / 24 | 400 | Основной текст, поля, кнопки (600) |
| Small | 14 / 20 | 400 | Подсказки, вторичные строки |
| Label | 12 / 16 | 600, caps, трекинг 0.06em | Подписи групп |
| Data | 16 / 24 | Plex Mono 500 | Номера, суммы, размеры |

Поля ввода — не меньше 16 px, иначе iOS масштабирует страницу при фокусе.

## Отступы, радиусы, высота

- Шаг 4 px: 4, 8, 12, 16, 24, 32, 48. Поля экрана — 16, между карточками — 12, внутри карточки — 16.
- Цель нажатия: 48 px по умолчанию на телефоне, не меньше 44 px (`06-frontend.md`); 40 px допустимо в таблицах панелей организации и суперадмина.
- Радиусы: `sm` 6 (бейджи), `md` 10 (кнопки, поля; `--radius`), `lg` 16 (карточки, листы), `full` (чипы).
- По умолчанию — рамка без тени. Тень — только у элементов над картой и у нижних листов.
- Фокус: кольцо 3 px `--ring` с отступом 2 px, всегда видимое при навигации с клавиатуры.

## Компоненты

Основа — shadcn/ui; ниже только то, что отличается от умолчаний.

| Компонент | Варианты | Правила |
| --- | --- | --- |
| `Button` | `accent`, `primary`, `secondary` (контур), `ghost`, `destructive` (контур) | `accent` — не больше одной на экран (Kup zezwolenie, Dodaj połów) |
| `Input`, `Select` | обычное, фокус, ошибка | Подпись над полем; ошибка — красная рамка + иконка + текст под полем; числовые значения — Plex Mono |
| `SegmentedToggle` | 2 сегмента | Выбор «Zabrana / Wypuszczona»; `aria-pressed` |
| `StatusBadge` | active, pending, expired, rejected, pendingSync | Иконка + текст; `pendingSync` — пунктирная рамка без заливки |
| `RuleAlert` | danger, warning, success | Заголовок и текст — перевод `code`; мелкой строкой `BR-xx · CODE` |
| `WaterCard` | подключённый / только реестр | Подключённый — метка «Zezwolenia online» и цена «от» |
| `CatchRow` | — | Вид, «Zabrana / Wypuszczona» и время, справа длина и вес (Plex Mono) |
| `BottomNav` | 4 раздела рыбака | Активный пункт — заливка Toń 100 и тёмный текст |
| `PermitTicket` | — | Тёмная шапка со статусом, QR, номер текстом, срок действия |
| `VerdictBanner` | valid, invalid | Вердикт проверки инспектора: заливка на всю ширину, иконка 56 px, H1 |

Строки компонентов — только через i18n-ключи.
