# ADR-0010: Prisma как ORM

- **Статус:** Принято
- **Дата:** 2026-10-06

## Контекст

Нужны типобезопасный доступ к PostgreSQL, миграции и быстрый старт.

## Варианты

1. **TypeORM** — привычен для NestJS, но слабее типизация запросов.
2. **Drizzle** — близко к SQL, отличные типы; меньше готовых примеров с NestJS.
3. **Prisma** — декларативная схема, генерируемые типы, миграции, Prisma Studio.

## Решение

Prisma 7.x (стабильная ветка; точная версия зафиксирована в `package.json`). Подключение — в `prisma.config.ts`, клиент — через драйвер-адаптер `@prisma/adapter-pg`. CHECK-ограничения и частичные индексы — SQL в файлах миграций (`--create-only`, затем правка).

## Последствия

- Схема `schema.prisma` — единый источник правды о структуре БД и основа ERD в дипломе.
- Сложные агрегаты статистики — через `$queryRaw` с tagged template.
