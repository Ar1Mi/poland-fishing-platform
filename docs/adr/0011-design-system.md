# ADR-0011: Дизайн-система интерфейса

- **Статус:** Предложено
- **Дата:** 2026-10-13
- **Связано:** NFR-06, ADR-0009, `06-frontend.md` → «UI-принципы», `10-design-system.md`

## Контекст

`06-frontend.md` фиксирует стек UI (Tailwind CSS + shadcn/ui) и принципы (mobile-first, крупные цели нажатия, высокий контраст), но не задаёт визуальный язык: цвета, шрифты, отступы, вид статусов. Без этого каждый экран среза (T-09…T-19) решал бы эти вопросы заново, а экраны разных ролей расходились бы.

Ограничения:

- основной сценарий — телефон на берегу, на солнце, одной рукой, часто без сети;
- три языка интерфейса (`pl`, `en`, `ru`) — шрифт должен покрывать польскую диакритику и кириллицу;
- PWA работает офлайн (ADR-0009) — шрифты должны быть доступны без сети;
- RODO: загрузка шрифтов с чужого CDN передаёт IP пользователя третьей стороне;
- диплом: один разработчик, времени на собственную библиотеку компонентов нет.

Макет дизайн-системы и четырёх демо-экранов подготовлен и одобрен 2026-10-13.

## Варианты

### Визуальный язык

1. **Тема shadcn/ui по умолчанию (нейтральная серая)** — ноль работы; но низкая узнаваемость, акцент и статусы всё равно придётся придумывать, контраст второстепенного текста на солнце слабый.
2. **Собственные токены поверх shadcn/ui** — компоненты и доступность берём готовые, меняем только CSS-переменные темы; нужно один раз описать токены и держать их в одном месте.
3. **Готовая дизайн-система (Material UI, Ant Design)** — много компонентов из коробки; но это замена принятого стека, тяжёлый бандл для PWA и чужой визуальный язык.

### Шрифты

1. **Системные шрифты** — ноль байт и офлайн без усилий; но разный вид на Android / iOS / Windows и нет моноширинного начертания с предсказуемыми цифрами для номеров и сумм.
2. **Google Fonts с CDN** — просто подключить; но не работает офлайн до первого кэширования и передаёт IP пользователя Google (проблема с точки зрения RODO).
3. **Шрифты в бандле (`@fontsource`)** — попадают в precache Service Worker, нет запросов к третьим сторонам; плюс две зависимости и около 100–150 КБ woff2 (после ограничения наборов символов latin, latin-ext, cyrillic).

## Решение

Собственные токены поверх shadcn/ui: основной цвет «Toń» (`#0B5D66`), единственный акцент «Spławik» (`#C2410C`), шаг отступов 4 px, радиусы 6 / 10 / 16. Шрифты Onest (текст) и IBM Plex Mono (номера, суммы, размеры) поставляются в бандле через `@fontsource`. Значения токенов и правила применения — в `docs/10-design-system.md`; в коде они живут только в теме Tailwind (`apps/web/src/index.css`), компоненты используют семантические имена, а не hex.

## Последствия

- Экраны всех ролей собираются из одних токенов и компонентов; смена палитры — правка одного файла.
- Статус всегда передаётся цветом, иконкой и текстом вместе — интерфейс не зависит от цветовосприятия и читается на солнце.
- Шрифты работают офлайн и не создают запросов к третьим сторонам.
- Жертвуем: две новые зависимости (`@fontsource-variable/onest`, `@fontsource/ibm-plex-mono`) и рост precache; тёмная тема в первой версии не делается.
- Оранжевый акцент допустим только для одного главного действия на экране — правило нужно соблюдать на ревью, линтером оно не проверяется.
- Сделать: T-05 — тема Tailwind с токенами, подключение шрифтов, базовые компоненты shadcn/ui (`Button`, `Input`, `Badge`, `Alert`, `Card`); `06-frontend.md` и `AGENTS.md` — ссылки на `10-design-system.md`.
