Каждое значимое решение — отдельный файл `NNNN-kebab-title.md` по шаблону `template.md`. Решения не переписываются: если передумали, создаётся новый ADR со статусом «Принято» и ссылкой «Заменяет ADR-NNNN», а у старого статус меняется на «Заменён ADR-MMMM».
