# ADR-0008: Правила ловли как данные, три уровня, самое строгое

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Связано:** FR-12, FR-16, BR-02…BR-06, ADR-0003

## Контекст

Wymiary и okresy ochronne задаёт rozporządzenie, но użytkownik rybacki может их ужесточать в регуламине, иногда для конкретного водоёма.

## Варианты

1. **Правила в коде** — каждое изменение требует релиза.
2. **Правила-скрипты / DSL** — гибко, но сложно и небезопасно.
3. **Параметрические правила в таблице + фиксированный набор проверок** — гибко в пределах известных типов ограничений.

## Решение

`SpeciesRule` с уровнями «общий / организация / водоём» (по заполненности FK). Эффективное правило — самое строгое значение каждого параметра. Проверки — фиксированный набор `CatchRule` (Strategy) в `packages/shared`.

## Последствия

- Новый тип ограничения (напр. дневной лимит на водоём, метод ловли) = новая колонка + новое правило-класс.
- Админ не может ослабить общие нормы — это защищает от ошибок ввода.
