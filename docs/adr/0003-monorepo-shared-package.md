# ADR-0003: Монорепозиторий pnpm и общий пакет `shared`

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Связано:** FR-12, FR-13, ADR-0008

## Контекст

Правила проверки улова должны работать одинаково на сервере и в PWA без сети. Коды ошибок, enum и схемы валидации тоже общие.

## Варианты

1. **Два репозитория** — дублирование типов и логики, рассинхронизация.
2. **Логика только на сервере** — офлайн-запись без мгновенной проверки, рыбак узнаёт о нарушении часы спустя.
3. **Монорепозиторий + `packages/shared`** — одна реализация CatchValidator, общие Zod-схемы и коды ошибок.

## Решение

pnpm workspaces: `apps/api`, `apps/web`, `packages/shared`. В `shared` — только чистый TypeScript без зависимостей от Node/браузера/Prisma.

## Последствия

- `shared` собирается в ESM + типы; оба приложения импортируют `@lowisko/shared`.
- Изменение правила проверяется одним набором unit-тестов.
- Enum Prisma и enum в `shared` должны совпадать — проверяется тестом.
