# ADR-0007: Каталог водоёмов + подключённые организации + внешние разрешения

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Связано:** FR-22…FR-27, сценарии Г и Д

## Контекст

Владельцы водоёмов могут не знать о сервисе. Если водоём появляется только после подключения организации, карта пуста и рыбаку платформа бесполезна («курица и яйцо»).

## Варианты

1. **Водоёмы создаёт только организация** — пустая платформа на старте.
2. **Каталог независим от организаций + claim + внешние разрешения** — ценность для рыбака с первого дня.

## Решение

`FishingWater` существует без организации (`UNCLAIMED`), каталог импортируется из публичных списков RZGW Wody Polskie и округов PZW (первый регион — Mazowsze), координаты — OSM. Организация получает водоём через `WaterClaim`, одобряемый суперадмином. На неподключённых водоёмах рыбак ведёт реестр по `ExternalPermit` с общими правилами.

## Последствия

- Нужен импорт CSV с идемпотентностью (`source + sourceRef`) и геокодированием.
- Улов ссылается ровно на одно из двух разрешений (CHECK).
- Данные каталога могут устареть — показываем источник и дату импорта.
