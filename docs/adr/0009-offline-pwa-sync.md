# ADR-0009: Офлайн-PWA для рыбака, синхронизация без Background Sync

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Связано:** FR-13, NFR-03, сценарий Б

## Контекст

На водоёмах часто нет связи. Нативное приложение вне рамок.

## Варианты

1. **Нативное приложение / React Native** — лучший офлайн, но второй кодбейс и публикация в сторах.
2. **PWA + Background Sync API** — не поддерживается Safari/iOS.
3. **PWA + очередь в IndexedDB + синхронизация по событию `online`, при открытии и вручную** — работает везде.

## Решение

Вариант 3: Dexie-очередь, `clientId` (UUID) с устройства, пакетный `POST /catches/sync`, серверная повторная валидация в порядке `caughtAt`.

## Последствия

- Идемпотентность через unique `clientId`.
- Конфликты лимитов между устройствами решает сервер; пользователь видит `REJECTED` с причиной.
- Офлайн-режим только для рыбака; админка и проверка — онлайн.
