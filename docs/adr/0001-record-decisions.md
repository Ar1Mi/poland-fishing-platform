# ADR-0001: Фиксировать решения в ADR

- **Статус:** Принято
- **Дата:** 2026-10-06

## Контекст

Проект пишется в основном агентом. Агент не помнит прошлых сессий, а в тексте диплома нужно обосновывать архитектурные решения альтернативами.

## Варианты

1. **Решения только в чате/коммитах** — теряются, агент принимает противоречивые решения.
2. **Один большой проектный документ** — неудобно ссылаться, история изменений не видна.
3. **ADR (короткий файл на решение)** — легко ссылаться, видна эволюция.

## Решение

ADR в `docs/adr/`, навык `/new-adr` создаёт файл по шаблону и обновляет индекс.

## Последствия

- Агент обязан остановиться и предложить ADR, если задача требует решения, которого нет в `docs/`.
- ADR напрямую переносятся в главы 4–5 диплома.
