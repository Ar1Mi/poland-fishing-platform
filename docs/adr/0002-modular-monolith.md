# ADR-0002: Модульный монолит на NestJS

- **Статус:** Принято
- **Дата:** 2026-10-06
- **Связано:** NFR-10

## Контекст

Один разработчик, ~20 недель, развёртывание на один VPS. Нужны чёткие границы модулей, которые легко описать в дипломе.

## Варианты

1. **Микросервисы** — независимое масштабирование; но сетевые вызовы, распределённые транзакции и инфраструктура несоразмерны объёму.
2. **Express без структуры** — быстро стартовать, но архитектура размывается.
3. **Модульный монолит на NestJS** — DI, модули, guards, interceptors, Swagger из коробки; один процесс и одна БД.

## Решение

Модульный монолит NestJS. Модули общаются через экспортированные сервисы, а не через чужие таблицы напрямую.

## Последствия

- Транзакции (одобрение claim, синхронизация уловов) — локальные транзакции PostgreSQL.
- При росте модуль можно выделить в сервис — границы уже есть (аргумент для «Podsumowanie»).
