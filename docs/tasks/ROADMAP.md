# ROADMAP

Задачи берутся по порядку; «Зависит от» должно быть `done`. Статусы: `todo` → `doing` → `done`. Агент меняет статус в таблице и отмечает критерии в описании задачи.

- Свои решения в рамках документов: просроченное приглашение — 422 `INVITATION_EXPIRED`, а не 401 `TOKEN_EXPIRED` (веб на 401 обновляет access-токен и повторяет запрос); приглашение принимается только кнопкой (не при открытии ссылки); аннулировать можно только `SCHEDULED`/`ACTIVE`; поиск проданных — по номеру, не по имени владельца; схема `Invitation` и `Membership` не менялась (ожидающее — `acceptedAt IS NULL`, одновременные приглашения — advisory-lock); `testcontainers` — прямая dev-зависимость API той же версии, что уже ставил `@testcontainers/postgresql` (Mailpit в E2E), без изменения версий в lockfile; новый демо-водоём «Staw Głęboczek» — для claim в сценарии Д (Wąsosze остаётся сценарию Г).
